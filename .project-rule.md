# ZeroSync Project Directives
- Adhere strictly to C# WPF Desktop MVVM standards (`[AgentOption]/standards/csharp/wpf.md`).
- View is pure XAML + zero code-behind logic. All interactions use Commands and Data Binding.
- Background I/O and UI synchronization must use `await _dispatcher.InvokeAsync()` and avoid blocking calls (`.Result`, `.Wait()`).
- Support Dual Publish (.NET Publish Release) via `publish.ps1`: Full (self-contained single-file) and Lite (framework-dependent single-file).
- Preserve Rclone integration safety: never expose sensitive tokens in unmasked plaintext UI logs.
